# Luo Chat: earned-link strategy

Prepared 25 October 2026. No outreach, submissions or link purchases performed.

## Prerequisites

Release a tested, accurately described product first. Use only the approved
canonical HTTPS host. Finalize contact/legal pages, fix demonstrated bugs and
confirm Search Console ownership. Never expose private conversations for SEO.

## First 30 days after approved release

1. Publish useful `/help` material: installation, password recovery, device storage,
   accessible controls and truthful privacy limitations. Use stable descriptive
   anchors; link each guide back to relevant help/contact pages.
2. Add one accurate website link to owner-controlled social/product profiles.
3. Publish a technical release note with reproducible build information and
   openly documented limitations; link the public repository only if the owner
   explicitly wants it promoted.
4. Ask consenting beta testers for feedback, not purchased or incentivized
   positive reviews. Quote only with explicit permission; do not invent metrics.

## Days 31–60

- Produce original guides about offline device-storage tradeoffs and accessible
  chat interactions, showing only synthetic/consented screenshots.
- Offer a small number of individually relevant accessibility, PWA or developer
  communities a useful article/demo through owner-approved outreach.
- Submit truthful listings to appropriate product directories only after the
  owner approves the text and the submission terms. Do not create dozens of
  accounts, spam comments, or seek reciprocal links as a ranking scheme.

## Days 61–90 and measurement

- Review Search Console indexing, query impressions, referring pages and quality
  feedback. Track qualified visits and recovery/help success, not raw link count.
- Fix obsolete public URLs with reviewed redirects and request correction of
  genuinely broken inbound links politely; keep old document paths working.
- Maintain a simple log of proposed source, owner consent, URL, date and result.
  Do not scrape personal contact lists or send bulk unsolicited email.
- Disclose sponsored placements and use the appropriate sponsored/nofollow link
  attributes. No paid-link networks, fake testimonials or guaranteed-rank claims.

## Ongoing content map

About → Help / Privacy / Contact. Help → Recovery / Storage / Permissions
sections and Connection checks. Every public page → Terms / Cookies / Privacy /
Copyright / Contact. None of these links grant access to private app content.
