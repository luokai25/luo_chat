About Luo Chat

Luo Chat is an independent messaging web app from Luo's Creations. It is designed for direct and group conversations, with optional media sharing, notifications and on-device features.

Who operates this site?

This is the official Luo Chat website hosted at luo-chat-luokai25.vercel.app. The service uses Supabase for authentication and application data, and Vercel for hosting. It is not Google, WhatsApp, or another messaging provider.

How do accounts work?

If you choose email sign-in, enter the password you created specifically for Luo Chat. We do not request your Google or email account password. If a Google sign-in option is available, it must go through Google's own authorization interface, not a form asking for your Google password.

Installation

Luo Chat is a progressive web app (PWA). Supported browsers may offer Install app or Add to Home Screen. Installation through the browser does not require an APK, unknown-source permission or bypassing browser security warnings.

Some advanced features depend on browser support, user permissions and service configuration. Luo Chat does not promise end-to-end encryption for all conversations.
